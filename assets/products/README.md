# Product photos

Drop your product photos into this folder with these exact filenames and they
will automatically appear on the landing page collection cards (portrait 3:4
photos work best — your studio shots are perfect):

| Filename                   | Card                |
| -------------------------- | ------------------- |
| `sharara-1.jpg`            | Shararas            |
| `crop-top-1.jpg`           | Crop Top Sets       |
| `gown-1.jpg`               | Gowns               |
| `palazzo-1.jpg`            | Palazzo Sets        |
| `short-top-palazzo-1.jpg`  | Short Top Palazzo   |
| `pant-set-1.jpg`           | 3-Pc Pant Sets      |

Until a photo is added, each card shows an elegant gold line-art garment
silhouette as a placeholder — the site never looks broken.

Tip: keep files under ~400 KB each (export at ~1200px on the long edge) so the
page stays fast.

To replace the generated monogram with your real brand logo, overwrite
`assets/logo.svg` (or add `assets/logo.png` and update the two `<img>` tags in
`index.html`).
